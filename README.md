# 🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript.

## 🚀 Live Demo
🔗 https://attdeep.github.io/Tic_tac_toe_game-_mini_project/

## 📌 Features
- Two-player gameplay (X and O)
- Winner detection
- Draw detection
- Restart game option
- Responsive and user-friendly design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

```
│
├── index.html

└── jsproject.js
```

## 🎯 How to Play

1. Player X starts the game.
2. Players take turns clicking empty boxes.
3. The first player to get 3 marks in a row, column, or diagonal wins.
4. If all boxes are filled and no player wins, the game ends in a draw.
